# Mona Studios Web Application

Veebirakendus loovstuudio Mona Studios jaoks.

## Funktsioonid

- töötubade kuvamine
- registreerimine töötubadesse
- administraatori paneel
- töötubade lisamine, muutmine ja kustutamine
- automaatne e-kirjade saatmine
- mobiilivaade

## Projekti käivitamine

Frontend:

npm install  
npm run dev

Backend:

node server.js
